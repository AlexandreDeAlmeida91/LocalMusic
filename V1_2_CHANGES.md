# LocalMusic V1.2 — Playlists locales

## Nouveautés

- Onglet **Playlists**
- Création de playlists personnalisées : Rap, Rock, Salle, Chill, etc.
- Ajout de plusieurs MP3 à une playlist
- Retrait d’un morceau d’une playlist sans supprimer le MP3
- Suppression d’une playlist sans supprimer les fichiers audio
- Bouton **Tout lire**
- Lecture d’un morceau dans le contexte de sa playlist
- Suivant / précédent suivent la playlist active
- Enchaînement automatique basé sur la file native `expo-audio`
- Boucle après le dernier morceau de la playlist
- Le lecteur affiche le nom de la file en cours
- Playlists enregistrées localement dans `playlists.json`
- Un même MP3 peut appartenir à plusieurs playlists sans dupliquer le fichier
- Si un MP3 est supprimé de la bibliothèque, il est retiré automatiquement de toutes les playlists

## Important

La V1.2 inclut aussi les corrections V1.1 pour la file native iOS et la lecture écran verrouillé.
