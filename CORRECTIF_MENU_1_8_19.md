# Peak Music 1.8.19 — ouverture du menu

Le menu ⋯ utilise désormais une fenêtre native transparente au-dessus de l’écran, avec un positionnement mesuré dans la fenêtre. Toucher ailleurs le ferme. Sur iOS, une action attend la fermeture complète du menu avant de présenter son écran.

Trois tests de comportement réussis : action différée après fermeture, annulation sans action, ouverture et positionnement borné. Export JavaScript iOS validé. La correction visuelle et tactile reste à vérifier sur iPhone, sans simulateur iOS disponible ici.
