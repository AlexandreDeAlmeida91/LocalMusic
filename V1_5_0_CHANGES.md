# LocalMusic V1.5.0 — thème Neon

Refonte graphique basée sur les maquettes validées.

## Nouveau design

- fond sombre bleu/noir avec halos violets ;
- boutons et sélecteurs avec accent violet ;
- cartes de morceaux et playlists sombres et arrondies ;
- mini-lecteur sombre avec bordure lumineuse ;
- page playlist harmonisée avec le reste de l’application ;
- lecteur plein écran sombre/violet ;
- page Paroles harmonisée avec le nouveau thème ;
- fenêtres de création et sélection de morceaux adaptées au mode sombre.

## Images

Aucune pochette de démonstration n’est intégrée dans l’application.

- les images des morceaux restent celles lues depuis les tags ID3 ;
- les images des playlists restent celles choisies par l’utilisateur ;
- lorsqu’aucune image n’existe, LocalMusic affiche uniquement son placeholder neutre.

## Fonctionnalités

La refonte ne modifie pas le moteur audio, les commandes écran verrouillé, le stockage V1.4.2, les playlists ou les paroles.

## Dépendances

Aucune nouvelle dépendance n’a été ajoutée. Le projet reste sur Expo SDK 57 avec les correctifs déjà attendus :

- `expo ~57.0.26`
- `expo-document-picker ~57.0.3`
